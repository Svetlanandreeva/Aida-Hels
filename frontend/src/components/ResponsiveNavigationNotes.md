Responsive navigation implementation notes for Aida.

- Desktop web (>=1024px): left sidebar.
- Narrow/regular mobile: bottom navigation.
- Very narrow screens (<360px): icons stay visible and labels may be hidden to avoid clipping.
- Tablet-width mobile/web keeps bottom navigation with a centered maximum width.
- Native safe-area bottom inset is respected.
- Existing five destinations and icon language are preserved.
